How to download all PDFs from a web page at once (5 ways)

Updated 2026-11-13

A course page with 40 lecture notes, a council site with years of meeting minutes, a supplier page full of spec sheets: clicking each PDF, waiting for the viewer and pressing Save gets old fast. Here are five ways to get them all, from zero-install tricks to a one-click batch.

First: make Chrome download PDFs instead of opening them

By default Chrome opens a PDF in its built-in viewer, so every link becomes two extra clicks. Change it once:

  1. Open Settings → Privacy and security → Site settings.
  2. Scroll to Additional content settings → PDF documents.
  3. Choose Download PDFs.

Also check Settings → Downloads. If Ask where to save each file before downloading is on, Chrome will pop up a Save dialog for every single file, which defeats the point of a bulk download. Turn it off while you work and switch it back later if you like it.

Method 1: Ctrl+click (or middle-click) each link

With the setting above, Ctrl+click (Cmd+click on a Mac) or middle-click starts a download without leaving the page. For 5–10 files this is honestly the quickest route and needs nothing installed. Beyond that it gets error-prone: it is easy to miss a link or grab the same file twice.

Method 2: list every PDF link with the browser console

When you want to see exactly which PDFs a page links to – or count them before downloading – the developer console can list them in a second.

  1. Press F12 (or Ctrl+Shift+J / Cmd+Option+J) and open the Console tab.
  2. Paste this line and press Enter:
copy([...new Set([...document.querySelectorAll('a[href]')].map(a => a.href).filter(h => /\.pdf($|[?#])/i.test(h)))].join('\n'))

It collects every link on the page whose address ends in .pdf (also when followed by ?… or #page=2), removes duplicates and copies the list to your clipboard. copy() is a helper built into Chrome's console, so paste the result into a text file or a spreadsheet column. Two things it will not catch:

  • Links that do not end in .pdf, such as /download?id=123 or /file.pdf/view. The server may still send a PDF, but the address does not say so.
  • Links that only appear after you scroll, open a tab or press Load more. Reveal them first, then run the line.

The console gives you the list, not the files. To download them in one go, feed the list to a downloader (method 4) or to wget (method 5).

Method 3: find PDFs across a whole site with Google

If the files are spread over many pages, search Google for site:example.com filetype:pdf, optionally with a keyword: site:example.com filetype:pdf annual report. This only shows what Google has indexed, so it can miss new or hidden files, but it is a good way to discover which pages hold the documents you need. Open those pages and use one of the other methods there.

Method 4: BatchGrab – pick and download in one batch

BatchGrab is a Chrome extension we make for exactly this job. It scans the page you are viewing and lists every downloadable file it finds – PDFs, documents, archives, images, audio and video links – so you can tick what you want and download it all at once.

  1. Install BatchGrab from the Chrome Web Store.
  2. Open the page with the PDFs. If it loads more items as you scroll, scroll to the bottom first, then click the BatchGrab icon (press Rescan if you scrolled after opening it).
  3. Filter to PDFs with one click, or search by file name or link text (for example "2025" or "minutes") to narrow the list.
  4. Select the files and press Download. You can pause, resume, cancel and retry failed files.

Method 5: wget for whole folders (command line)

If you are comfortable with a terminal, wget can fetch every PDF linked from a page:

wget -r -l 1 -nd -A pdf https://example.com/reports/
  • -r -l 1 follows the links on that one page, one level deep.
  • -nd saves all files into the current folder instead of recreating the site's folder tree.
  • -A pdf keeps only files ending in .pdf.

To download a saved list instead, put one URL per line in links.txt and run wget -i links.txt. By default wget stays on the same domain, so PDFs hosted on a different server (a CDN, for example) are skipped, and it cannot see links that a page builds with JavaScript or shows only after you log in. For those cases the browser methods above work better because they see the page exactly as you do.

Which method should you use?

  • Under 10 PDFs: Ctrl+click each link.
  • Need a list or a count: the console line, pasted into a spreadsheet.
  • 10–100 PDFs on one or a few pages, no coding: BatchGrab.
  • A large public folder and you like the terminal: wget.

Troubleshooting

The PDF opens in a new tab instead of downloading.Set PDF documents to Download PDFs as shown at the top, or right-click the link and choose Save link as….

Some files are missing.The page probably loads more items as you scroll or behind a "Load more" button. Reveal everything first, then scan again.

The downloaded file is tiny or will not open.You likely saved an HTML page (a login screen or a viewer page) rather than the PDF itself. Open the link in the browser, sign in if needed, and download from the page you are logged into.

Files have random names like 8f3a2c.pdf.That is the name the website gave them. BatchGrab Pro can rename files using the link text, a running number, the domain or the date.

Please only download files you have the right to save, and respect each site's terms. Downloading from YouTube and streaming sites is not supported.
