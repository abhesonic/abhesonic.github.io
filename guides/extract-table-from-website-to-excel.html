How to extract a table from a website to Excel or Google Sheets (4 ways, no coding)

Updated 2026-10-29

You found a price list, a directory or search results on a web page and you want them in a spreadsheet. Here are the four ways that work in 2026, from quickest to most powerful.

1. Copy and paste (works for simple HTML tables)

Select the table with the mouse, press Ctrl+C, click a cell in Excel or Sheets and press Ctrl+V. If the result lands in one column, use Paste special → Text or Data → Split text to columns. It breaks on lists made of cards, on merged cells and on anything that loads as you scroll.

2. Excel: Data → Get Data → From Web

Paste the page address, let Excel's Power Query find the tables, pick one and press Load. Great for proper <table> elements on public pages; it cannot see data that appears only after you log in, scroll or click, and it does not work in Excel for Mac for every page.

3. Google Sheets: =IMPORTHTML

In a cell type =IMPORTHTML("https://example.com/page", "table", 1). The last number is which table on the page you want (try 1, 2, 3...). Use "list" instead of "table" for bulleted lists. Same limits as above: public page, real HTML tables, nothing behind a login.

4. TableGrab (Chrome extension) – for lists, cards and multi-page results

TableGrab reads the page you are already looking at, including pages behind your own login, and finds both tables and repeated lists such as product cards or search results. Click the icon, untick the columns you do not need, rename them and press CSV (free) or Excel (Pro). Press Find it to point it at the page's Next button and it collects the following pages too. Everything stays in your browser; nothing is uploaded.

  1. Install TableGrab from the Chrome Web Store.
  2. Open the page with the data and click the TableGrab icon.
  3. Check the preview, adjust columns, download.

Try it first on the practice page, which has three pages of sample products.

Which one should you use?

  • One small table on a public page → copy-paste or IMPORTHTML.
  • Tables that change every day and you want them to refresh → Excel Get Data from Web.
  • Cards, results, directories, pages with Next/Load more, or pages behind your login → TableGrab.

Please only collect data you are allowed to use, and respect each website's terms.
