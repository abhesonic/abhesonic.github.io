How to extract all links from a web page into Excel or Google Sheets (4 ways)

Updated 2026-11-20

A supplier's product list, a directory of members, a page of event listings, the links on your own site you want to audit: copying URLs one by one with right-click → Copy link address is slow and error-prone. Here are four ways to get every link, with its text, into rows and columns.

Method 1: one line in the browser console (any page, any spreadsheet)

This works on whatever page you have open, including pages that need a login, because it reads the page exactly as your browser shows it.

  1. Open the page and scroll down until everything you need has loaded.
  2. Press F12 (or Ctrl+Shift+J / Cmd+Option+J on a Mac) and open the Console tab.
  3. Paste this line and press Enter:
copy('Text\tURL\n' + [...new Map([...document.querySelectorAll('a[href]')].map(a => [a.href, a.innerText.trim().replace(/\s+/g, ' ')])).entries()].map(([u, t]) => t + '\t' + u).join('\n'))

It collects every link, removes duplicate addresses, and copies a two-column list (link text, then URL) to your clipboard. Click cell A1 in Excel or Google Sheets and paste: the tab between the two values puts them in separate columns. URLs come out complete (https://…) even when the page uses short relative links like /about.

If Chrome refuses to paste and shows a warning, type allow pasting, press Enter, and paste again. That warning exists to stop people from running code a stranger sent them, so only paste code you understand. This line only reads links and copies text; it changes nothing on the page.

Method 2: Google Sheets IMPORTXML (public pages, refreshes by itself)

For a public page that you want to re-check now and then, Google Sheets can fetch the links itself. Put the page address in B1 and use:

=IMPORTXML(B1, "//a/@href")

This lists the href of every link. =IMPORTXML(B1, "//a") gives the link texts, but the two lists do not always line up row for row (image links have no text, for example), so use Method 1 or 4 when you need text and URL paired.

IMPORTXML returns addresses as written in the page's HTML, so many will be relative (/pricing, //cdn.example.net/file.js). With the raw links in column A starting at A2, and the site's base address (for example https://example.com, no trailing slash) in E1, this turns them into full URLs:

=ARRAYFORMULA(IF(A2:A="", "", IF(REGEXMATCH(A2:A, "^https?://"), A2:A, IF(LEFT(A2:A, 2)="//", "https:"&A2:A, IF(LEFT(A2:A, 1)="/", $E$1&A2:A, "")))))

Anything else – #top anchors, mailto: and tel: links, and the less common paths without a leading slash – is left blank so you can check it by hand.

Limits: IMPORTXML only sees the HTML the server sends, so links that a page adds with JavaScript, behind a login or after scrolling are missing. Some sites block Google's fetcher entirely, which shows up as an error or "Imported content is empty".

Method 3: Excel – paste, then pull the URL out of each hyperlink

Select the links on the page, copy, and paste into Excel. The cells keep their link text and stay clickable, but Excel has no built-in formula that returns a cell's hyperlink address. A tiny custom function does it:

  1. Press Alt+F11 (on a Mac: Tools → Macro → Visual Basic Editor), choose Insert → Module, and paste:
Function GetURL(c As Range) As String
    If c.Hyperlinks.Count > 0 Then GetURL = c.Hyperlinks(1).Address
End Function
  1. Back in the sheet, if the pasted link is in A2, enter =GetURL(A2) in B2 and fill down.
  2. Save as .xlsm (macro-enabled), or copy column B and Paste Special → Values before saving as .xlsx.

This works in Excel for Windows and Mac desktop, not in Excel for the web. Copy-paste also brings along whatever else you selected, so expect some tidying.

Method 4: TableGrab – links from lists, cards and results pages

Often you do not want every link on the page (menus, footers, social icons) but the links inside the actual content: each product, each listing, each search result, together with its name, price or date. TableGrab is a Chrome extension we make for that. It finds the tables and repeating lists on the page and turns them into rows, with text, links and image addresses in separate columns.

  1. Install TableGrab from its page and open the page with the list.
  2. Click the TableGrab icon. A panel opens beside the page with the data already in rows and columns.
  3. Untick the columns you do not need, then press CSV to download or Copy to paste into your spreadsheet.
  4. Results split over several pages? Press Find it, point at the page's Next button, then Start. "Load more" buttons and pages that keep loading as you scroll work too.

Cleaning the list once it is in your sheet

  • Remove duplicates: =UNIQUE(B2:B500) in Excel 365 or Google Sheets, or Data → Remove duplicates.
  • Only links to your own site (Google Sheets): =FILTER(B2:B500, REGEXMATCH(B2:B500, "^https?://(www\.)?example\.com(/|$)")). Wrap it in NOT(…) to get only outside links.
  • Get the domain of each URL: in Excel 365 =TEXTBEFORE(TEXTAFTER(B2, "//") & "/", "/"), in Google Sheets =REGEXEXTRACT(B2, "^https?://([^/?#]+)"). Both turn https://shop.example.com/a?b=1 into shop.example.com. Then a pivot table or =COUNTIF shows which sites you link to most.

Which method should you use?

  • Every link on one page, right now: the console line.
  • A public page you want to re-check later: IMPORTXML in Google Sheets.
  • Links you already pasted into Excel: the GetURL function.
  • Links inside product lists, directories or results, especially over several pages: TableGrab.

Troubleshooting

Some links are missing.The page loads more as you scroll or after a click. Scroll to the end or press "Load more" first, then run the console line or rescan.

I get javascript:void(0) or # instead of a URL.That link is a button that runs code instead of going to an address. There is no URL to copy; the real address only appears after the click.

The URLs have long tracking codes.Strip everything after the question mark with =TEXTBEFORE(B2&"?", "?") in Excel 365 or =REGEXEXTRACT(B2, "^[^?]*") in Google Sheets, but check first that the page still opens without it.
