How to scrape a table from a website into Google Sheets with IMPORTHTML (and what to do when it fails)

Updated 2026-11-06

Google Sheets can read a table straight off a public web page with one formula, and keep it updated. It is free and needs no add-on. It also fails on many modern sites. Here is how to use it properly, how to read its errors, and what to do when it simply cannot see the data.

1. The basic formula

In an empty cell type:

=IMPORTHTML("https://example.com/prices", "table", 1)

  • URL – the full address in quotes, including https://. You can also put the address in a cell (say B1) and write =IMPORTHTML(B1, "table", 1), which makes it easy to swap pages.
  • "table" or "list" – "table" reads HTML <table> elements; "list" reads bulleted and numbered lists (<ul> and <ol>).
  • Index – which table or list on the page, counting from 1 in the order they appear in the page code. Pages often contain hidden or layout tables, so if 1 gives the wrong data, try 2, 3, 4 and so on.

The result spills down and to the right, so leave enough empty cells. If anything is already in the way you get a #REF! "would overwrite data" error; clear the cells and it fills in.

2. Keep only the columns and rows you need

You rarely want the whole table. Wrap the import instead of deleting columns by hand (deleting cells inside the result breaks it):

  • One column: =INDEX(IMPORTHTML(B1,"table",1),0,2) returns the whole second column. The 0 means "all rows".
  • Several columns, filtered and sorted: =QUERY(IMPORTHTML(B1,"table",1),"select Col1, Col3 where Col3 > 100 order by Col3 desc",1). With imported data, QUERY names the columns Col1, Col2… (capital C, no letters like A or B). The last 1 tells it the first row is a header.
  • Drop the header row: =QUERY(IMPORTHTML(B1,"table",1),"select * offset 1",0). The 0 at the end says there is no header, so offset 1 skips the first row.
  • First 20 rows only: add limit 20 to the end of the QUERY text.

If numbers come in as text (for example $1,299 or 12 345), QUERY may treat the column as text and the > 100 filter will not work. Add a helper column with =VALUE(REGEXREPLACE(C2,"[^0-9.\-]","")) to strip currency signs and thousands separators. If the page uses a comma as the decimal mark, use the optional fourth argument for the page's locale, for example =IMPORTHTML(B1,"table",1,"de_DE").

3. Combine several pages into one list

When the same table is split across page 1, page 2 and page 3, put the three addresses in B1:B3 and stack the results:

=VSTACK(IMPORTHTML(B1,"table",1), QUERY(IMPORTHTML(B2,"table",1),"select * offset 1",0), QUERY(IMPORTHTML(B3,"table",1),"select * offset 1",0))

The first import keeps its header; the others skip it so the header is not repeated. All parts must have the same number of columns. This is fine for a handful of pages; every extra import makes the sheet slower and Google limits how much a single sheet can fetch, so it is not practical for 50 pages.

4. Data that is not in a table: IMPORTXML

Product cards, search results and directories are usually built from <div> boxes, not tables, so IMPORTHTML returns nothing. IMPORTXML can pick elements with an XPath expression:

  • All second-level headings: =IMPORTXML(B1,"//h2")
  • All link addresses on the page: =IMPORTXML(B1,"//a/@href")
  • Elements with a certain class: =IMPORTXML(B1,"//div[@class='price']")

To find the right class, right-click the value in Chrome and choose Inspect. Each IMPORTXML returns one column, so building a full table (name, price, link) means one formula per column and hoping the rows line up. It works, but it is fiddly and breaks when the site changes its code.

5. Common errors and what they mean

MessageUsual causeWhat to try
Imported content is emptyThe data is added by JavaScript after the page loads, so Google's fetcher sees an empty page.IMPORTHTML cannot fix this. Use a browser-based tool (below).
#N/A Could not fetch URLThe page needs a login, blocks automated requests, or the address is wrong.Open the URL in a private window. If you must sign in to see it, Sheets cannot see it either.
Wrong table or a tiny tableThe index points to a layout or hidden table.Try index 2, 3, 4…
Loading… for a long timeSlow site or too many import formulas in one file.Reduce the number of imports; put each source on its own tab.

6. Refreshing and freezing the data

Import formulas are refreshed by Google on its own schedule (typically about once an hour while the file is in use), and you cannot force an exact time. Changing the URL cell re-fetches immediately. If you want a fixed snapshot – yesterday's prices, for example – select the result, copy it, and use Paste special → Values only on another tab. That copy will never change.

When IMPORTHTML is the wrong tool

Use the formula for public pages with real HTML tables that you want to keep live. It struggles with:

  • pages you can only see after signing in (your own dashboards, supplier portals, marketplaces);
  • results that appear as cards or tiles, or load more as you scroll;
  • data spread over many pages with a Next or Load more button.

For those, a tool that reads the page in your own browser is simpler.
