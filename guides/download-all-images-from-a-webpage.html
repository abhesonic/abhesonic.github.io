How to download all images (or PDFs) from a web page at once

Updated 2026-10-29

Right-clicking fifty images one by one is nobody's idea of fun. Here is how to grab them all in one go.

1. Save the page as "Web page, complete"

Press Ctrl+S in Chrome and choose Web page, complete. Chrome saves the HTML plus a folder with the images it had loaded. Fast, but you get thumbnails instead of full-size images, odd file names, and nothing that was still to be loaded while scrolling.

2. Developer tools → Network → Img

Press F12, open the Network tab, filter by Img, reload the page and right-click each entry to save. Accurate, but still one file at a time.

3. BatchGrab (Chrome extension) – list, filter, download in one batch

BatchGrab scans the page you are on and lists every image (including the full-size version behind lazy-loaded thumbnails), PDF, document and file link. Filter by type or name, tick what you want and press Download. Files are named sensibly and sorted into folders; you can pause, resume and retry.

  1. Install BatchGrab from the Chrome Web Store.
  2. Scroll the page to the bottom once so lazy-loaded images appear, then click the BatchGrab icon.
  3. Filter (for example "Images" or ".pdf"), select, Download.

Free: up to 20 files per batch. Pro (US$9.99 one-time) removes the limit and adds ZIP mode, rename patterns, folders by site and type, and collecting from all open tabs.

Tips

  • If Chrome asks where to save every file, turn off Ask where to save each file before downloading in Chrome settings, or use ZIP mode.
  • Downloading from YouTube or streaming sites is not supported, and please respect copyright and each site's terms.
