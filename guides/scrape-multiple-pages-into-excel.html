How to scrape data from multiple pages into Excel (pagination without coding)

Updated 2026-11-27

A directory with 40 pages of members, search results that show 25 items at a time, a product category that keeps loading as you scroll: copying one page is easy, collecting all of them into one sheet is where most people give up. This guide shows how to get every page into Excel or Google Sheets, which method fits which kind of page, and how to clean up the result.

Step 1: find out what kind of pagination the site uses

Go to page 2 of the list and look at the address bar. Almost every site falls into one of three groups:

  • Page number in the URL, for example …/members?page=2 or …/results/page/2/. The easiest case: you can build every page address yourself.
  • Offset in the URL, for example …?start=25 or …?offset=50. The number is the position of the first row, not the page number.
  • The URL does not change. You click Next or Load more, or new rows appear as you scroll. The data is loaded by JavaScript, so formula-based methods usually cannot see it.

Step 2: work out how many pages there are

Most lists say something like "487 results" and show a fixed number per page. The number of pages is the total divided by the page size, rounded up:

=ROUNDUP(487/25, 0)

That gives 20 pages. The last one is not full: 19 full pages hold 475 rows, so page 20 has the remaining 12. Keep this in mind when you check your result: 487 rows in the sheet means nothing was lost.

Step 3: build the list of page URLs

In Excel 365 or Google Sheets, one formula writes all the addresses. For a page number in the URL:

="https://example.com/members?page=" & SEQUENCE(20)

For an offset URL with 25 rows per page, the first page starts at 0, the second at 25, and so on:

="https://example.com/search?start=" & (SEQUENCE(20)-1)*25

The last address ends in start=475. Open the first and last URL in your browser to check they show the right rows before you import anything.

Method 1: Excel Power Query, one function for every page

Excel's Get Data from Web imports one page. To import all of them, you turn that import into a small function and run it once per page number. This works in Excel for Windows (2016 and later, including Microsoft 365). Power Query in Excel for Mac supports fewer data sources, so the web import may not be available there; use Method 2 or 3 on a Mac.

  1. Go to Data → Get Data → From Other Sources → Blank Query. The Power Query editor opens.
  2. Click Advanced Editor, delete what is there and paste the code below. Change the address and the number of pages.
  3. Click Done, check the preview, then Close & Load.
let
    GetPage = (n as number) =>
        let
            Source = Web.Page(Web.Contents("https://example.com/members?page=" & Number.ToText(n))),
            Data = Source{0}[Data]
        in
            Data,
    Pages = {1..20},
    Tables = List.Transform(Pages, each GetPage(_)),
    Combined = Table.Combine(Tables),
    NoDuplicates = Table.Distinct(Combined)
in
    NoDuplicates

Source{0} is the first table on the page. If your data is the second table, use Source{1}; import a single page with From Web first to see which number the Navigator gives it. For an offset URL, replace Number.ToText(n) with Number.ToText((n-1)*25). Later, Data → Refresh All fetches every page again.

Limits: Power Query reads the HTML the server sends. If the rows only appear after JavaScript runs, after a login, or the URL never changes, the preview will be empty or show the wrong table. Some sites also block automated requests; then there is nothing a formula can do.

Method 2: Google Sheets, one IMPORTHTML per page

Put the page URLs from Step 3 in column A (A2:A21). In B2, import the first page:

=IMPORTHTML(A2, "table", 1)

Because each import spills several rows, you cannot simply fill this formula down. For a handful of pages, stack them with VSTACK and drop the repeated header rows by removing duplicates:

=UNIQUE(VSTACK(IMPORTHTML(A2,"table",1), IMPORTHTML(A3,"table",1), IMPORTHTML(A4,"table",1)))

Use "list" instead of "table" when the data is a bulleted list. This is fine for 3 to 10 pages; beyond that the formula gets long and Google may slow down or refuse some fetches. The same JavaScript and login limits apply as in Method 1. Our IMPORTHTML guide covers errors like "Imported content is empty".

Cleaning the combined data

  • Repeated header rows: filter the first column for the header text (for example "Name") and delete those rows, or use =FILTER(A2:D1000, A2:A1000<>"Name").
  • Duplicates (sites often repeat an item at the edge of two pages): Data → Remove Duplicates, or =UNIQUE(A2:D1000) in Excel 365 and Google Sheets. To see them first, put =COUNTIF(A:A, A2)>1 next to each row: TRUE means the value appears more than once.
  • Count check: =COUNTA(A2:A1000) should match the total the site shows (487 in the example). Fewer rows usually means a page failed to load or the last page was skipped.
  • Numbers stored as text ("$1,299" or "4.5 stars"): =VALUE(SUBSTITUTE(SUBSTITUTE(B2,"$",""),",","")) turns a price into a number you can sort and sum.

Which method should you use?

  • Page number or offset in the URL, public page, Excel: Power Query (Method 1). It refreshes with one click.
  • A few public pages, Google Sheets: IMPORTHTML with VSTACK (Method 2).
  • Next button, Load more, endless scroll or a page behind your login: TableGrab (Method 3).

Troubleshooting

Every page returns the same rows.The site ignores the page number in the URL and loads the next rows with JavaScript. Use a browser-based method like Method 3.

Power Query says the table cannot be found.The page has a different number of tables than page 1, or the data is not an HTML table. Check with From Web on one page and change Source{0}.

The import stops halfway or shows errors.The site limits how fast you can request pages. Import fewer pages at a time, or collect them in the browser instead.
