FAQ

Chrome asks where to save every single file

Turn off Ask where to save each file before downloading in Chrome Settings → Downloads, or use Save as one ZIP (Pro) to get a single prompt.

Some images are missing

Many sites load images only when you scroll. Scroll to the bottom of the page, then press Rescan.

Does it download from YouTube?

No. Downloading from YouTube is not allowed by the Chrome Web Store policies. Please only download files you have the right to save.
